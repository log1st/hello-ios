# HelloTrust

Минимальное SwiftUI-приложение: кнопка, по нажатию — алерт. Заведено, чтобы
проверить всю цепочку «собрали → поставили на живой айфон» **без Apple Developer
Program**, до того как в неё поедет настоящий кошелёк.

```
цель установки   iOS 18.0 и выше (значит, ставится и на 26, и на 27 beta)
подпись          бесплатный Apple ID, срок жизни сборки 7 дней
bundle id        com.log1st.hellotrust
```

## Открыть у себя

Проекта в репозитории нет намеренно — он генерируется:

```sh
brew install xcodegen
xcodegen generate
open HelloTrust.xcodeproj
```

## Поставить на телефон

### Путь A — Xcode, если версия Xcode подходит под систему телефона

1. Xcode → Settings → Accounts → добавить свой Apple ID (бесплатный годится).
2. Target HelloTrust → Signing & Capabilities → Team = твоя Personal Team.
3. Подключить айфон, выбрать его целью, ⌘R.
4. На айфоне: Настройки → Основные → VPN и управление устройством → доверить
   профиль разработчика.

Оговорка: чтобы Xcode вообще увидел устройство на бета-системе, версия Xcode
должна знать эту версию iOS. На iOS 27 beta нужен Xcode 27 beta.

### Путь B — готовый .ipa, версия Xcode не важна

1. В Actions взять артефакт `HelloTrust-unsigned-ipa` последнего прогона.
2. [Sideloadly](https://sideloadly.io) на маке: перетащить `.ipa`, ввести свой
   Apple ID, Start. Он подпишет сборку твоим сертификатом и поставит по кабелю.
3. Доверить профиль в настройках, как выше.

Этот путь не требует, чтобы Xcode понимал версию системы на телефоне, — поэтому
на бете он надёжнее первого.

## Что важно помнить

- Сборка, подписанная бесплатным Apple ID, **перестаёт запускаться через 7 дней**.
  Лечится переустановкой; SideStore умеет обновлять подпись сам, в фоне.
- Одновременно на устройстве живут **3** таких приложения, и регистрируется не
  больше **10** App ID за 7 дней.
- Пуши и iCloud бесплатной подписи недоступны. Всё, что внутри приложения —
  экраны, Keychain, сеть, камера, — работает.
